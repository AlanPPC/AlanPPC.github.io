# Cerro Kallami — Página Web

Proyecto web para el Taller de Proyectos, Carrera de Informática, mención Ingeniería de Sistemas.

## Estructura

- `index.html` — contenido de la página.
- `style.css` — diseño visual.
- `script.js` — menú móvil y botón volver arriba.
- `img/` — imágenes del proyecto.
- `video/video-final.mp4` — video final.
- `presentacion/presentacion.pdf` — presentación.

## Cómo usarlo

1. Reemplaza `Tu Nombre` en `index.html`.
2. Coloca la portada en `img/portada.jpg`.
3. Coloca las imágenes del storyboard en `img/` y cambia los bloques `ESCENA 01`, etc., por etiquetas `<img>`.
4. Coloca el video en `video/video-final.mp4`.
5. Coloca tu PDF en `presentacion/presentacion.pdf`.
6. Sube todo el contenido a un repositorio de GitHub.
7. En GitHub: Settings → Pages → Deploy from branch → selecciona `main` y `/root`.
